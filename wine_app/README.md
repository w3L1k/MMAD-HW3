# Оценка качества вина

Streamlit-приложение оценивает вероятность того, что вино получит экспертную оценку не ниже 7 баллов. Модель обучена в `HW3_Germanov.ipynb`; при запуске приложения обучение не выполняется.

## Запуск

Проверено локально с **Python 3.14.7**. Откройте терминал в папке `wine_app` и выполните:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

На Windows вместо `source .venv/bin/activate` используйте `.venv\Scripts\activate`. После запуска откройте адрес, который появится в терминале (обычно `http://localhost:8501`). Остановка сервера — `Ctrl+C`.

Если зависимости уже установлены в существующем окружении, достаточно запустить `python -m streamlit run app.py` из этой папки.

## Содержимое

- `app.py` — интерфейс и расчёт метрик;
- `model.joblib` — сохранённый пайплайн `StandardScaler` + `LogisticRegression`;
- `config.json` — исходный порог рекомендации;
- `test.csv` — тестовая выборка для вкладки «Модельные метрики»;
- `requirements.txt` — версии библиотек, использованные при проверке.

Во вкладке «Оценка одного вина» можно задать 12 признаков. Вкладка «Модельные метрики» показывает матрицу ошибок, precision, recall, F₁, ROC- и PR-кривые при выбранном пороге. «Пакетное предсказание» принимает CSV с теми же 12 признаками (без `target`), показывает вероятности и решения и позволяет скачать результат. Последняя вкладка отображает коэффициенты модели.

Порог задаётся в боковой панели и действует для одиночного и пакетного предсказаний, а также для метрик. Вероятности на тестовой выборке кэшируются и не пересчитываются при перемещении ползунка.
