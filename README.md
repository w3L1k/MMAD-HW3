# Решение ДЗ №3 по ММАД

## Выполнил: Германов Артём, БПИ 248

Основное решение заданий по логистической регрессии, метрикам классификации и работе с несбалансированными классами находится в [HW3_Germanov.ipynb](HW3_Germanov.ipynb). Данные для работы — [wine_quality.csv](wine_quality.csv).

В папке [wine_app](wine_app) находятся Streamlit-приложение, обученная модель, тестовые данные и инструкция по локальному запуску. Приложение позволяет оценить одно вино, посмотреть метрики при разных порогах и загрузить CSV для пакетного предсказания.

**Развёрнутое приложение:** [germanovhw3.streamlit.app](https://germanovhw3.streamlit.app)
